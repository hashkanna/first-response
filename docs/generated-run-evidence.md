# Actual generated-repair execution

These results are individual cloud executions on 19 September 2026, not benchmarks
or guaranteed timings. The faults and tests are controlled fixtures. The repair
edits were generated by Gemini from the broken source, observed evidence and
failing reproduction; no authored candidate library was supplied to that agent.

## Payment timeout

Incident: `inc-fdfec64eadbf`. Gemini/Pydantic AI diagnosed the injected change from
3000 ms to 3 ms, then `gemini-3.8-flash` generated three candidates in one request
(2702 input tokens, 286 output tokens). The UI measured 10.0 seconds from alert to
verified candidates.

| Generated assignment | Reproduction | Regressions | Overall |
| --- | --- | --- | --- |
| `PAYMENT_TIMEOUT_MS = 3000` | 1 passed | 24 passed | 25/25 passed |
| `PAYMENT_TIMEOUT_MS = 1000` | 1 passed | 24 passed | 25/25 passed |
| `PAYMENT_TIMEOUT_MS = 5000` | 1 passed | 23 passed, 1 failed | 24/25 passed; approval unavailable |

The rejected candidate failed `test_provider_timeout_remains_enforced`: a payment
that should time out instead completed. This is an actual regression failure,
not a staged loser. Two generated candidates legitimately satisfied the tests.

The operator selected the 3000 ms patch through the browser's diff review and
approval dialog. Fresh Modal recovery passed all 25 tests and 12 checkout probes.
The event became `resolved`, and only the chosen card was marked applied.

The broken Python snapshot was bound to SHA256
`bb17a12d28e10016d38afb75b874bdd67c05e81eff2dd61a09c67b423f1953b4`.
See the [public execution receipt](evidence/generated-timeout.json) for exact
events, source diffs, provider usage and Modal test output.

## Missing coupon

Incident: `inc-a873fb3af5dd`. In one generation request (2809 input tokens,
267 output tokens), Gemini produced three distinct guarded assignments:

- An explicit `cart.coupon is not None` conditional.
- A truthiness conditional on `cart.coupon`.
- `getattr(cart.coupon, "code", None)`.

Each passed the reproduction and all 24 regressions. The UI measured 8.8 seconds
to verified candidates. The operator selected the explicit `is not None` guard
through the review dialog; fresh Modal recovery passed 25 tests and 12 checkout
probes. [Inspect the public receipt](evidence/generated-coupon.json).

A prior spoken approval attempt was recognized but safely denied because the
provider omitted the final-transcript flag required by the approval gate. The
successful approval above was an explicit browser button action, not speech.

## Voice input

An actual `gemini-3.8-live` session transcribed synthesized speech sent as PCM16 at
16 kHz, returned native audio at 24 kHz, and reported interruption during a second
spoken command. Explicit negation did not approve the waiting repair. A separate
read-only reconnection also returned native speech. All eight smoke checks passed.

This verifies the real provider input/output path using synthetic speech. It does
not substitute for a human microphone/headset rehearsal. Detailed audio receipts
and the earlier authored-candidate runs are in [verification evidence](verification-evidence.md).
